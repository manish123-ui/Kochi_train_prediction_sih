# Data

## The real dataset is NOT in this repository
The original notebook trained on `kochi_induction_dataset.csv` (4,500 rows x 19 columns, as printed by
the notebook) and, for the score experiment, on `Copy of output_mileage_mtd_scored(1).csv` (columns
unknown; never visible in the notebook). Both are private and excluded by `.gitignore`.

To use your own data, place the induction file at:

```
data/raw/kochi_induction_dataset.csv
```

or pass `--data path/to/file.csv` to any command. Column meanings are in
[`docs/data_dictionary.md`](../docs/data_dictionary.md).

## Synthetic sample (for smoke tests only)
`data/sample/synthetic_kochi_induction_sample.csv` is **synthetic**: 25 fake trainsets (`SYN-01`...) x 60 days,
generated by `python -m src.main generate-sample`. It has the same columns as the real file so the code
can run end to end, but:

* values are random; `FinalDecision` follows an arbitrary made-up rule (not a Kochi Metro rule);
* `Daily_Km_Assigned` is 0 for Standby and random for Service purely by construction;
* any metric computed on it is meaningless and says nothing about the real data or real operations.

Regenerate with another size/seed:

```bash
python -m src.main generate-sample --n-trainsets 30 --n-days 90 --seed 7
```
